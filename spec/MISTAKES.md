# Mistakes

The rewrite's mistakes, counted by kind, each kind with the rules that stop it (the owner, 2026-11-12; condensed to
rules on 2026-11-25: "makde mistakes condense so they are rules"). A mistake is fixed where it is found, the turn it is
found; then its kind's count goes up by one, or a mistake no row fits gets a row. A row holds rules and what holds them,
never a history of mistakes met (the owner, 2026-11-14: "Mistakes are supposed to be caught very quickly, not that they
become their own maintenance"). A kind that grows while its holder stands moves that holder up a rung the same turn,
from a rule here to the rule file that loads with that kind of file, then to a tool that refuses it, and its row names
the new holder (the owner, 2026-11-23: "its not log and forgotten, its to enforce progressive learning").
`scripts/land-unit.sh` refuses a landing in which a kind grew while its row and every file the row names stood. The
orient prints every row at a start and after a compaction, and every agent reads them before each piece. The history
is in git: the 135 entries of 2026-11-12 to 2026-11-14 at 2a4a56b59, and the rows before this condensing at f2986ea66.
