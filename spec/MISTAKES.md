# Mistakes

Each kind of mistake the rewrite has met, and what stops it. A mistake is fixed where it is found and wherever its
cause is shared, and a kind no row names gets a row; no count and no rule line is written for each mistake (the owner,
2026-11-26: "drop the count nonsense, it has not helped"). A kind that recurs is stopped by a tool that refuses it
before it runs. The counted rows are in git at 8f12a2fb3.

| Kind | What stops it |
|---|---|
| Acted or proposed before its cost and risk were weighed | before an agent starts, a long run or a proposal to the owner: its cost, its risk and its source, read first |
| Written from memory, not read at its source at HEAD | `git grep` and `git show` at HEAD before the line is written; the compiler; `tests/Alis.Reactive.ArchitectureTests/WhenARuleNamesTheCode.cs` |
| A rule or a tool's list not applied before the change | the rule that governs a change, opened before it; `scripts/land-unit.sh`, `scripts/gate.sh` and the test rules TEST001 to TEST013 |
| A number, a proof line or an absence not read from its run | the run's own result line, read when it printed; `scripts/plant-defect.sh` |
| A shell command or a script wrong in its own terms | `.claude/hooks/refuse-known-traps.mjs` and the deny rules of `.claude/settings.json` |
| Said to the owner in a way that blurs what holds | what ran, by its line, apart from what was assumed and what did not run |
| A costly agent run before its environment ran the brief's commands | a low-effort probe of those commands first (`.claude/skills/delegate/SKILL.md`) |
| A fault in an agent's work that its brief gave no instruction for | the brief names the instruction; a fault it did not name is the lead's |
| The toolchain kept where the system deletes it | `scripts/toolchain-env.sh` and `scripts/doctor.sh` |
| The lead's own process put before the product | the Markdown path for Markdown alone; one push per unit |
