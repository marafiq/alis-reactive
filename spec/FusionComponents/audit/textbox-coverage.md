## What does a template callback receive and return?

textbox.js:389–435 compiles the prefix and suffix and asks each function to fill its own destination. Base template.js:62–66 preserves a supplied function. Base template-engine.js:28–32 then calls the original function with five arguments: null data, the live TextBox, the literal template name, the prefix/suffix destination element, and an undefined root. The separate browser observation records the argument count, instance identity, input type and destination class on both renders. The template ID, string-template flag and index from the outer call do not reach the original callback as separate arguments.

TemplateArgs.TemplateName is the complete Argument<string>(2) operation, matching the third string passed by the vendor. Each callback captures its own field’s declared FusionTextBox.Type when the page installs it on the contact or the adjacent extension. The two configured controls have different channels on the same card. Capturing the first field for both gives the wrong extension label. Rebuilding after a channel change asks each callback again. A fixed string from the first call leaves the old directions in place. Callback<TemplateArgs,string>.Set writes a real function (Members.cs:146–169). Each answer chooses between app-authored FusionTemplate strings, which the vendor interprets as HTML (template-engine.js:57–68).

Reaching the actual TextBox at argument 1 as a live declaration, returning a DOM node list, and manipulating the positional destination element remain open. Argument<T> is a data operation. ALIS023 rejects chaining a positional declaration and a projection inside one property body. The MVC wrapper CLR type describes a server render model. JsObject.cs:67,155,241 provides named and returned live-object holders and a positional data read. Callback<TArgs,TResult> returns a TypedSource<TResult> and Argument<T> yields a data source. The declaration cannot promise identity for a DOM node collection through a serialized list of application objects. Raw HTML from a resident’s entry is outside these care examples. Neither callback alias claims a property getter across the vendor’s string, function and null union.
