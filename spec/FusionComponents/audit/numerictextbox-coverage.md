## Which source boundaries remain?

- Reads of a configured finite bound work on the int stock field. After null writes EJ2 emits the finite extrema of JavaScript Number. Only the two nullable-double reads in X1628 claim those extrema. No int or decimal receipt can safely represent those default numbers.
- A CSS width and a numeric width share one vendor slot. The author has two typed writes. Reading it as a single scalar loses the alternative type. Likewise the template slot can hold a closure, selector or markup, and no single typed scalar represents every read.
- The pinned affixed scale held `placeholder: Weight to record` through Never→Always→Never. The visible input attribute was absent after the return to Never and reappeared on Refresh. The live-created clear span carries the accessible label `close` and lacks the explicit button role that initial widget rendering assigns. These source-observed differences govern the real X1612/X1620 gestures.
- The pinned compiler throws `TypeError: this.iconTemplateFunction is not a function` when an empty template string reaches NumericTextBox.createAppendTemplate. Both directions compile with the same falsey check in numerictextbox.js:538–554. Null removal is the supported empty-template action and is rendered in X1623.
- The component's declared template is `string | Function`, while its implementation invokes vendor compilation and framework adapters. The callback captures its own declared field for the live component. The remaining positional integration arguments, arbitrary function objects and non-string React template results lack a distinct typed MVC use.
- The HTML attribute object is unrestricted at both declaration and source. An explicit helper dictionary must retain the actual bound member name whenever it replaces the constructor map. Both live source and literal writes can rebind the original id or create competing form names. The input identity constraint applies to both.
- Focus and blur on the mounted input produce the standard browser focus event. Touch, keyboard and pointer can lead to that event without changing its subtype. The optional union does not by itself establish separate publication of each physical originating event.
- The public setters for original wrapper event handler names, including Change, Focus, Blur, Destroyed and Created, accept JavaScript callback names as strings. The typed reactive listener owns the first four, and created is excluded by the standing decision. Vendor raw builder construction, Render and WriteTo keep the original generator and writer lifetime; a second direct mount cannot replace the registered MVC field.
- The two render overloads use the existing unconstrained TValue for both target frameworks. The author supplies a numeric member compatible with its live values. A null configuration delegate to the callback overload is rejected by its existing ArgumentNullException for `build`; the standard overload passes a concrete empty delegate.
- A restored plain input after destroy no longer contributes the numeric hidden form field. The original Chromium form experiment saw entries `[["TowelsSigned","8"]]`, `[["TowelsSigned","0"]]`, `[["TowelsSigned",""]]` and finally `[]` after destruction. X1625 files the enhanced bound field; X1617 uses the released control to transcribe a paper count.
- Local Chromium exercises net10. MVC5 browser execution is the Windows job. The two original package assemblies/XML and both target manifests are separate source and compatibility evidence.
