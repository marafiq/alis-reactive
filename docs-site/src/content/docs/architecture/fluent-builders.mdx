The fluent builders are Layer 1 of the architecture — the developer's API surface. Every method call creates a **plan model** (a data structure), not a side effect. The plan collects these models. `Html.RenderPlan(plan)` serializes them to JSON. The runtime executes the JSON.

```d2
direction: right

call: "Developer writes\nfluent C# in .cshtml" {
  shape: rectangle
  style.fill: "#e8f0fe"
  style.stroke: "#4285f4"
  style.font-size: 18
}
model: "Plan models created\nStartsWhen + ReactionGraph" {
  shape: rectangle
  style.fill: "#fef7e0"
  style.stroke: "#f9ab00"
  style.font-size: 18
}
plan: "Plan collects\nBehaviors + components" {
  shape: rectangle
  style.fill: "#e6f4ea"
  style.stroke: "#34a853"
  style.font-size: 18
}
json: "Html.RenderPlan(plan)\nJSON in the page" {
  shape: rectangle
  style.fill: "#d4edda"
  style.stroke: "#34a853"
  style.font-size: 18
}

call -> model: builds {
  style.stroke: "#4285f4"
}
model -> plan: collects {
  style.stroke: "#f9ab00"
}
plan -> json: serializes {
  style.stroke: "#34a853"
}
```

## The boundary rule

The C# side builds plan models. It never touches the DOM, never calls `fetch`, never evaluates conditions. The JS side reads the plan and executes it. It never creates new reaction kinds, never extends the generated contract, never invents behavior.

If a feature can't be expressed as a plan model, it doesn't exist in the framework. The plan is the only contract.

## Why plan models instead of direct execution?

Because Razor rendering and DOM execution happen at different times. C# runs on the server during Razor view rendering — the DOM doesn't exist yet. The JS runtime runs after the page loads — the C# code is long gone. Plan models bridge this gap: the C# side captures *what* must happen, serializes it as JSON, and the runtime executes it later.

This also means the C# API is compile-time checked. Rename a model property → every `m => m.Name` expression breaks at build. Wire a condition on `args.Checked` → the compiler enforces that `Checked` is `bool?`, not `object`. The type safety lives in the builders. The runtime just follows instructions.
