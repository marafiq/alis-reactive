A native checkbox still reads `el.checked`. A Syncfusion date picker still reads `el.ej2_instances[0].value`. What changed in V2 is where that knowledge lives: the runtime no longer guesses from ad hoc payload fields. Component slices declare their capabilities once, and plan authoring lowers them into contracts, objects, and bindings.

For the general execution model, see [Runtime](../runtime/).

## What a component slice declares

Each input component declares three pieces of authoring metadata in C#:

| Field | Purpose | Example |
|-------|---------|---------|
| **Vendor** | Which resolver family to use | `"native"` or `"fusion"` |
| **ValueMemberPath** | Which member path represents the canonical field value | `"value"`, `"checked"` |
| **ComponentType** | Which semantic component kind the slice represents | `"textbox"`, `"datepicker"` |

When you write `Html.InputField(plan, m => m.DueDate).FusionDatePicker(...)`, the slice registers that metadata once. Plan authoring then lowers it to:

- a capability contract for that component kind
- a runtime object for the rendered instance
- a binding for the model field's canonical value member

The browser runtime only sees the lowered V2 model. It resolves an object, resolves a member, and executes the requested action.

Only the resolver knows vendor-specific details such as `ej2_instances[0]`. Everything else operates on named members from the contract.

## Every interaction follows one pattern

| Interaction | Plan carries | Runtime does |
|-------------|-------------|-------------|
| **Read** (bindings, conditions, gather) | object + member | resolve object, walk member path |
| **Write** (SetValue, SetChecked) | object + member | resolve object, set member |
| **Call** (DataBind, ShowPopup) | object + member | resolve object, invoke member |
| **Wire event** (.Reactive) | object + event contract | subscribe and shape event payload |

## Adding a new component — zero runtime changes

If the new slice can be expressed with the existing contract/member model, runtime code does not change. You add the slice, declare its value member path and events, and authoring lowers it to the same V2 document shape as every other component.
