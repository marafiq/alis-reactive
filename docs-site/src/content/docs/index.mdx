Alis.Reactive is for .NET developers who want browser behavior without
handwritten JavaScript in Razor views.

The public DSL has a small shape. Create a `ReactivePlan<TModel>`, render
model-bound inputs and components, attach triggers, and use the pipeline for
browser work.

The last step is always explicit: render the plan once with
`Html.RenderPlan(plan)`.

```csharp
@{
    var plan = Html.ReactivePlan<TodoModel>();
}

@{ Html.InputField(plan, m => m.Title, o => o.Label("Title"))
    .NativeTextBox(b => b.Placeholder("What needs to be done?")); }

@(Html.NativeButton("save-btn", "Save")
    .Reactive(plan, evt => evt.Click, (_, p) =>
    {
        p.Post("/Todo/Save", g => g.IncludeAll())
         .Validate<TodoValidator>("todo-form")
         .Response(r => r.OnSuccess(s =>
             s.Component<FusionToast>()
              .SetContent("Saved")
              .Success()
              .Show()));
    }))

@Html.RenderPlan(plan)
```

The JSON plan is the contract. C# does not execute browser behavior. The runtime
does not invent behavior outside the plan.
