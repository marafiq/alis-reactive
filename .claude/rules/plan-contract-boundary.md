# Plan Contract Boundary — C# Plan Domain → Generated TS → Runtime Handler

Loads when plan-domain, serialization, or contract files are touched. Root
`CLAUDE.md` (Architecture) is authoritative; this rule carries the boundary
steps and per-layer checks.

## Before writing plan-domain code, verify

- This is a Value Object with invariants enforced by the constructor.
  Why: invalid state propagates through the pipeline and surfaces as wrong browser behavior.
- The expected plan shape is written out, and you know whether it changes the
  generated TS contract.
- Visibility is deliberate: `internal` for API protection, `public` only for
  exposed surface. Why: 5 constructors left public once cascaded across 170+ files.
- The plan carries ALL information the runtime needs — the runtime is a direct
  executor. Why: logic in the runtime lives outside the C# domain where it
  could have been made unrepresentable.
- Adding a new component does not require modifying existing descriptors (OCP).
  Why: 100+ vertical slices planned — each shared-descriptor change risks all of them.

## Boundary: C# plan domain → generated TS contract

`runtime/types/plan.ts` is generated by `PlanContractGenerator` — never
hand-edited (hook-enforced). JSON schema is retired; this file is the only contract.

1. Change the C# plan model / builder.
2. Regenerate (`npm run typecheck` runs generation first, or
   `npm run generate:plan-types -w Alis.Reactive.Assets`).
3. `npm run typecheck` — a runtime/contract mismatch fails here.
4. Add the runtime handler (new switch case + `assertNever` keeps the union exhaustive).
5. Prove behavior with a Playwright test on a sandbox page.
6. Commit C# + regenerated contract + runtime + test together.

Why generated, not authored: a hand-maintained contract drifts from C#
silently. Generation makes drift a typecheck failure instead of a runtime surprise.

Typecheck proves the shapes line up, NOT that the runtime does the right thing
with them. A field that type-checks but means the wrong thing is caught only by
Playwright, which is the only verification.
