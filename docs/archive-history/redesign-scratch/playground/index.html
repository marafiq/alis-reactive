This is the new 12-module design — 9 concept slices a .NET developer already thinks in (Trigger, Reaction, Condition, Value, Request, Component, Slot, Validation, Plugin) plus 3 shared kernels (Shape, Kind, Plan).

Module map — click any module to read its single responsibility, what it owns across all four layers, and which modules it depends on (and why).

Every arrow points downward: kernels at the bottom, slices in the middle, the Plan root on top. The graph is acyclic by construction.
