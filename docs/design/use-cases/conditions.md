Classification rules applied:
- **PROVEN**: a real gesture or page load and a visible assertion that changes if the use case breaks.
  For a **source** row, a broken read must flip the asserted outcome. For an **operator** row, the
  test must exercise a matching and a non-matching input (the outcome crosses), so the operator is
  told apart from its neighbours. When the exact boundary is not exercised, the row says so.
- **WEAK**: a test exists but would still pass with the behavior broken.
- **PLAN-ONLY**: only an NUnit fixture asserting plan JSON (no browser).
- **NONE**: no test.
