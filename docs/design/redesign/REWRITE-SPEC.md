## 0. Mission & the zero-feature-loss oracle

Clean-break green-field rewrite to **1.0.0**. **DONE = 1.0.0 released**, all 14 decisions honored, the oracle green in a fresh clone.

**Oracle (verified this session):** **1168** Playwright `[Test]` across **133** files + **192** vitest `it/test` across 28 files + typecheck + drift-check. Two tiers: (a) **FROZEN** user-visible behavior (DOM/text/focus/disabled/gather-body) — immutable; if it fails, the rewrite is wrong, never weaken it; (b) **UPDATABLE** plan-shape assertions — migrate OUT of Playwright INTO C# domain unit tests; they change only as documented wins (e.g. whole-payload kind, delivery-mode field).

**Architecture rule:** DSL → Rich **public** Plan Domain → hand-authored `plan.ts` → dumb runtime executor. ## 1. The 14 binding decisions (authoritative)

1. **Public domain model, ZERO `InternalsVisibleTo`** (delete `Alis.Reactive.csproj:69-72`: Fusion/Native/FluentValidator/PlanTypeGenerator). Internal ctors stay, behind public factories/builders. Any consumer onboards against the public surface.
2. **Component/plugin = a typed description of a JS object's public API**: `Property<T>` (read), `Function<T>` (method→value), `Command` (void method), `Event<TArgs>` (typed callback). All typed via `Shape`. **Arrays first-class** (already solved).
3. **Vendor DROPPED as a tag** → two declared data: (a) **root-accessor path** (`getElementById(id)`→JS object: native = element/empty; Fusion = `["ej2_instances","0"]`; 3rd-party = theirs) + (b) **event delivery mode** (`DomEvent` = unwrap `CustomEvent.detail` | `CallbackArgs` = pass-through — SF uses callbacks, native uses DOM events; verified `event-fusion.ts`/`event-native.ts`). `Fusion*`/`Native*` *name prefixes* survive; the runtime vendor `switch` dies.
4. **Onboard ONCE via DI** (singleton catalog, `AddReactiveComponents()`, like `AddReactiveFluentValidation`); the **plan is a consumer** (no per-view `RegisterPlugin`); serializer emits **only referenced** contracts.
5. **Ids are framework-controlled by the algorithm** (`IdGenerator`) — the **merge join key**; NEVER a raw string for onboarding. String ids ONLY for gather keys + DOM-target refs (`Element("x")`, `NativeButton("x")`). `IdFor(m => m.X)` is a **read-only** public accessor.
6. **Model-less "pure view" plan** (`Html.ReactivePlan()`, no `TModel`) for views with no model binding — **cannot have `InputField`** (an input IS a model binding); ids controlled via view-path algorithm.
7. **Free-monoid carrier = IMMUTABLE cons list** (`Cons|Nil`), not `List<T>`/`LinkedList<T>`, at the integration point (reaction sequence, trigger behaviors, condition first-match, slot/plan recompose). Keyed concerns (components-by-key, active/boot/slots) **stay maps**.
8. **Byte-stable render ⇒ cacheable**; plans are **value-free** w.r.t. request data (route/identity = runtime reads, never baked literals); partials = fragment cache + monoid concat.
9. **KILL the C#→TS codegen middle layer**: delete `PlanContractGenerator`, `tools/PlanTypeGenerator`, `generate:plan-types`, the `PlanTypeGenerator` IVT. **Hand-author `plan.ts`** under a strict linter; re-point the drift detector to **`--check`** committed `plan.ts` (never regenerate).
10. **Target BOTH `net48` and `net10.0`** (multi-target with `Directory.Build.props` centralization).
11. **Ratified names:** `FocusOut→Blur`; `ComponentRef.SetText` **KEEP**; pipeline callback `(value, p)` **value-first**. **Pending:** `#34` `FromDom` builder, `#36` `AsPluginSource` (ratify or park in `09`).
12. **Fix the 6 verified grill defects** in `11`: #2 cite, P3 contradiction, §1.5 NativeButton false premise, #6 `09:413` KEEP mis-cite, #16/#17 catalog reversal, #36 `AsPluginSource` not in `09`.
13. **NO BLOAT** (reproducing any dissolved god-file = failure) + **Matt-Pocock pure-behavior TDD** (red fixture first; behavior as one sentence; assert ONLY user-visible; tests change only on user-visible behavior change).
14. **Freeze sequence:** grill → ratify+freeze DSL → AST → UI → determinism proof (per-module + whole) → projects (keep `Alis.Reactive.*`) → freeze tests → mechanical code. Conflict-fixes for decisions 1/3/4/9 land in the ratify step BEFORE AST/determinism consume them.

## 5. Component module re-cut: vendor dropped (D2, D3, D5)

A component is a typed JS-object public API: `Property<T>` / `Function<T>` / `Command` / `Event<TArgs>` + `Shape`; arrays first-class. The **vendor tag is removed from the carrier**; replaced by **root-accessor path** + **event-delivery-mode**. Runtime: `getElementById(id)` → walk root path → JS object → generic member ops (`obj[prop]`, `obj.method(args)`, `obj.addEventListener(channel, cb)`); delivery-mode decides `CustomEvent.detail` unwrap vs callback-args pass-through. No `switch(vendor)`. `IdFor(expr)` exposes the controlled id read-only; string ids only at gather-key/DOM-target boundaries. Fusion/Native re-expressed through this one public surface ⇒ the 4 IVT lines delete (dogfood = sufficiency proof against the oracle). POC: `/tmp` (temp, runnable) proves declaration→`ComponentContract`→JSON.

## 9. Byte-stable, value-free, cacheable plans (D8)

Byte-stable render (proven `07`: byte-identical ×2) ⇒ a plan is a pure function of (view DSL, model type) ⇒ cacheable. Plans are **value-free**: route/identity are runtime reads, never baked literals (audit the DSL for any literal sourced from a live model instance — the sole cache-breaker). Partials: cache each immutable fragment, compose per-request by monoid concat. **New claim:** cached-fragment concat == fresh-fragment concat (a determinism law, §11).
