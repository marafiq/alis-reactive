## 1. Responsibility · Owns · Depends

**Responsibility (one sentence).** The structural type tag that rides on every
value, operand, gather assignment, and contract member — CLR inference at
authoring, one conversion engine at runtime — so the same bytes convert the same
way everywhere.

**Owns** (from `02-micro-modules.md`, names from `03-naming.md`):

| Side | Owns |
|---|---|
| `→` C# authoring/plan | `Shape` (value object), `ShapeStructure` (scalar/object/array/nullable axis), `ShapeObjectContract` (closed/open field set), `ShapeContractCompatibility` (the merge/accept algebra), `ShapeJsonConverter` (write-only wire emission) |
| `⇒` TS runtime | `ShapeConverter` — the single `applyShape` / `convertByShape` engine in `core/shape-convert.ts`; `RuntimeShape` wrapper in `domain/runtime-shape.ts`; the **shape-once rule** on the gather egress path (`formatForWire`) |
| contract | the generated `Shape` discriminated union in `types/plan.ts` (10 variants) — produced by **Kind**'s `PlanContractGenerator`, not hand-authored here |

**Depends on.** *Nothing.* Shape is the bottom kernel of the dependency graph
(`00-design.md` §2 graph: `Kind → Shape`, `Value → Shape`, every slice reaches
Shape; Shape reaches no one). It must not import `Value`, `Kind`, `Plan`, or any
slice. The only runtime import permitted is the `Shape` *type* from `types`
(structural, generated by Kind) — never a behavior module.

**Invariant the whole module exists to enforce — shape-once** (`00-design.md` §3,
`04-matrix-http-arrays-values.md` SHAPE-ONCE): a value is shaped exactly once, on
the gather/compare egress path. Authoring infers the `Shape` from the CLR type;
the runtime converts to wire form once via `formatForWire`. No re-derivation per
stage. This replaces the three redundant re-shapings the baseline carried
(evaluate / gather re-derive / `formatForWire`).

## 2. Public Surface

> "Public" here means the surface other modules call — in this repo that is
> almost entirely `internal` (Rule 8: the API surface is frozen; plan-model types
> have `internal` constructors and factory entry points). The only genuinely
> `public` members are the equality contract STJ and consumers rely on. The TS
> counterpart is `export`ed because it crosses the runtime module boundary.

### 2a. C# — `Shape` (the value object)

```csharp
namespace Alis.Reactive.PlanModel;

/// <summary>
/// Declares the expected structural type for a value in the plan
/// (string, number, boolean, date, array, object, nullable, raw, any, or none).
/// Carried on every value expression, condition operand, gather assignment,
/// and contract member so both C# and the runtime convert the same bytes the
/// same way. Null is unrepresentable: there is no null Shape — use
/// <see cref="None"/> for "absence of a typed value".
/// </summary>
public sealed class Shape : IEquatable<Shape>
```

| Member | Signature | Intent (XML-doc-style) |
|---|---|---|
| `String` | `internal static readonly Shape` | The scalar string shape. |
| `Number` | `internal static readonly Shape` | The scalar number shape. Covers **exactly** the eleven built-in numerics: `byte sbyte short ushort int uint long ulong float double decimal`. `nint`/`nuint` are **not** numeric → `Any` (Shape.cs:106–111). |
| `Boolean` | `internal static readonly Shape` | The scalar boolean shape. |
| `Date` | `internal static readonly Shape` | The scalar date shape (DateTime/DateTimeOffset/DateOnly). |
| `Raw` | `internal static readonly Shape` | A value passed through verbatim — no conversion. |
| `Any` | `internal static readonly Shape` | An unclassifiable value; accepts/merges with anything. |
| `None` | `internal static readonly Shape` | Absence of a typed value. The sentinel that replaces null — never an exception target. |
| `FromClrType` | `internal static Shape FromClrType(Type type)` | Infer the shape from a CLR type. The one authoring inference entry point every slice calls. **Ordered**: `Nullable<T>`→`Nullable(inner)`; `string`→string; `bool`→boolean; date(`DateTime`/`DateTimeOffset`/`DateOnly`)→date; one of the eleven built-in numerics→number; `Guid`/`TimeSpan`/`TimeOnly`→string; `enum`→string; **supported collection**→`ArrayOf(item)`; else `Any`. A **supported collection** is an array, OR a type whose generic-collection interfaces (`IEnumerable<T>`/`IReadOnlyCollection<T>`/`IReadOnlyList<T>`/`ICollection<T>`/`IList<T>`/`List<T>`/`HashSet<T>`/`ISet<T>`) resolve to **exactly one distinct** `T`. A non-generic `IEnumerable` (e.g. `ArrayList`), a dictionary, `string`, or a type with **two distinct** `IEnumerable<T>` → **not** supported → `Any` (Shape.cs:120–199). |
| `FromValue` | `internal static Shape FromValue(object? value)` | Infer from a runtime value instance; `null`→`None`, else `FromClrType(value.GetType())`. |
| `CollectionItemShapeOrNone` | `internal static Shape CollectionItemShapeOrNone(Type type)` | The element shape of a collection type, or `None` if the type is not a supported collection. |
| `ArrayOf` | `internal static Shape ArrayOf(Shape item)` | An array of `item`. Item must not be `None` (an array of nothing is unrepresentable). |
| `ObjectOf` | `internal static Shape ObjectOf(Dictionary<string, Shape> fields)` | A closed object with the named field shapes. |
| `OpenObject` | `internal static Shape OpenObject()` | An object that allows additional, undeclared fields. |
| `Nullable` | `internal static Shape Nullable(Shape inner)` | A nullable wrapper around a scalar/object/array. Inner must not be `None`. |
| `Kind` | `public string Kind { get; }` | The discriminator token: `string`/`number`/`boolean`/`date`/`array`/`object`/`nullable`/`raw`/`any`/`none`. Matched by the TS `Shape` union (Kind kernel). |
| `IsNone` | `internal bool IsNone` | True when this is the `None` shape. |
| `IsScalar` | `internal bool IsScalar` | True when serializable to a single string (string/number/boolean/date, or nullable wrapping a scalar). Gates HTTP headers, route params, query strings. |
| `TryGetArrayItemShape` | `internal bool TryGetArrayItemShape(out Shape itemShape)` | Element shape when this is an array; otherwise `None` + false. |
| `TryGetObjectContract` | `internal bool TryGetObjectContract(out ShapeObjectContract contract)` | The object field contract when this is an object; otherwise `None` + false. |
| `TryGetNullableInnerShape` | `internal bool TryGetNullableInnerShape(out Shape inner)` | Inner shape when this is nullable; otherwise `None` + false. |
| `IsNullableOf` | `internal bool IsNullableOf(Shape inner)` | True when this is `Nullable(inner)`. |
| `DescribeContract` | `internal string DescribeContract()` | Human-readable contract string (`array<…>`, `nullable<…>`, `object{a:string,…}`) for diagnostics. |
| `WriteContractDetails` | `internal void WriteContractDetails(Utf8JsonWriter, JsonSerializerOptions)` | Write the kind-specific JSON body (`item`/`inner`/`fields`+`additional`); the `kind` field is written by `ShapeJsonConverter`. |
| `Equals` / `==` / `!=` / `GetHashCode` | `public` | Structural equality by `Kind` + structure contract. Two shapes are equal iff they describe the same type contract. |

> **Why these and only these.** Each factory maps to exactly one TS `Shape`
> variant; each `TryGet…` maps to one `ShapeStructure` subclass. There is no
> setter, no mutable state, no second inference path. `IsScalar` exists because
> the HTTP egress (headers/route/query) is the one caller that must reject
> non-scalars; do not invent a parallel predicate elsewhere.

### 2b. C# — `ShapeStructure` (the structure axis, `internal abstract`)

Closed family of five sealed subclasses, all `private` inside `ShapeStructure`,
reached only through the static factories. A developer adds **no** new subclass
without a matching TS variant + a `PlanContractGenerator` reflection case.

### 2e. TS — `ShapeConverter` (`core/shape-convert.ts`, the one engine)

Crosses the contract. `Shape` here is the **generated** union from `types/plan.ts`
(owned by Kind). This module is the single place Shape→value conversion happens.

```ts
/** Discriminated result — caller MUST check .ok before using .value. */
export type ConvertResult<T> = { ok: true; value: T } | { ok: false; error: string };

/** The ONE entry point: coerce a raw value to its declared Shape, returning the
 *  original value on a conversion miss (never throws on a type mismatch). */
export function applyShape(value: unknown, shape: Shape): unknown;

/** Like applyShape but surfaces the miss as Err instead of returning the original. */
export function convertByShape(value: unknown, shape: Shape): ConvertResult<unknown>;

/** Scalar coercions, each total, each returns ConvertResult — exported for reuse.
 *  Edge rules are PINNED (shape-convert.ts) — the plain-object case is the only Err:
 *  toString : missing→"" ; string→itself ; number/boolean→`${v}` ; Date→ISO ;
 *             ARRAY→`String(v)` (comma-joined, NOT Err) ; plain object→Err.
 *  toNumber : missing→0 ; number→finite-or-Err ; BOOLEAN→1/0 ; string→Number(s) finite-or-Err
 *             (""/whitespace→0, "abc"→Err) ; Date→getTime finite-or-Err ; plain object→Err.
 *  toBoolean: missing→false ; boolean→itself ; string→truthy (false ONLY for ""/"false"/"0";
 *             "no"/"off"→true) ; number→truthy (false for 0/NaN) ; Date→true ;
 *             ARRAY→length>0 ([]→false) ; plain object→Err.
 *  toDate   : MISSING→ok(NaN) (not 0) ; Date→getTime ; number→treated as epoch ms (finite-or-Err) ;
 *             "YYYY-MM-DD"→LOCAL midnight ms ; other string→`new Date(s).getTime()` finite-or-Err. */
export function toString(value: unknown): ConvertResult<string>;
export function toNumber(value: unknown): ConvertResult<number>;
export function toBoolean(value: unknown): ConvertResult<boolean>;
export function toDate(value: unknown): ConvertResult<number>;   // epoch ms; missing→NaN; date-only→LOCAL midnight
export function toArray(value: unknown): ConvertResult<unknown[]>;       // array→self; missing/""→[]; plain object→Err; scalar→[v]
export function toPlainObject(value: unknown): ConvertResult<Record<string, unknown>>; // plain object only; array/Date/scalar→Err
```

`applyShape` / `convertByShape` switch on `shape.kind` with a final
`const _: never = shape;` arm so a missing variant is a compile error (Kind's
exhaustiveness contract). `string/number/boolean/date` → scalar coerce, returning
the **original value** on a miss (`applyShape`) or the `Err` (`convertByShape`);
`array` → `toArray` then recurse item shape; `nullable` → missing→`null` else
recurse inner; `raw/any/none` → identity. The **object** arm is pinned
(`applyObjectFields`, shape-convert.ts:113–127): `toPlainObject` first; if
`additional && zero declared fields`, return the input **unchanged**; otherwise
build a fresh record (copying all input keys first when `additional`), then for
each *declared* field **skip it entirely when the input lacks that key**
(`hasOwnProperty` false → `continue`) — an absent declared field is **never
materialized to its zero**. Only present declared fields are shaped.

### 2f. TS — `RuntimeShape` (`domain/runtime-shape.ts`, the wrapper + shape-once)

```ts
export class RuntimeShape {
  static from(shape: Shape): RuntimeShape;
  static unshaped(): RuntimeShape;                          // { kind:"none" }
  static declaredBy(producer: ValueExpression): RuntimeShape;

  get planShape(): Shape;
  get isDeclared(): boolean;                                // kind !== "none"

  item(): RuntimeShape;                                     // array element shape, else unshaped
  orDeclared(declared: Shape): Shape;                       // this shape if declared, else fallback

  apply(value: unknown): unknown;                           // applyShape when declared, else passthrough
  applyEach(items: unknown[]): unknown[];
  convert(value: unknown): ConvertResult<unknown>;

  /** SHAPE-ONCE egress: convert a runtime value to its wire form exactly once.
   *  PINNED (runtime-shape.ts:58–72): undeclared(`none`)→passthrough; `nullable`→
   *  recurse the inner shape; a `date` whose value is a **finite number** →
   *  `new Date(value).toISOString()` (UTC, millisecond precision, `…Z`); everything
   *  else — including a `date` whose value is NaN or already a string — passes
   *  through unchanged. This is the only re-shaping permitted on the gather path. */
  formatForWire(value: unknown): unknown;
}
```

## 3. Input → Output Contract

| Flow | In | Out | Invariants (by construction, not guarded) |
|---|---|---|---|
| **Authoring inference** | a `Type` (`FromClrType`) or `object?` (`FromValue`) | a `Shape` | Total: every CLR type maps to a shape; unclassifiable → `Any`, never null. `null` value → `None`. There is no code path that returns a null `Shape`. |
| **Construction** | factory args | a `Shape` | `ArrayOf`/`Nullable` reject a `None` item/inner (an array/nullable of nothing is unrepresentable) — these are the only constructor invariants, and they guard a *developer mis-call at authoring*, the real boundary. `ObjectOf` requires non-null `fields`. No public ctor (Rule 8). |
| **Equality** | two `Shape` | bool | Structural: equal iff same `Kind` and same structure contract (recursive). `GetHashCode` agrees with `Equals`. Drives matrix de-dup and merge fast-paths. |
| **Serialization** | a `Shape` + `Utf8JsonWriter` | `{ "kind":"…", <body> }` | Write-only (`Read` throws `NotSupportedException` — plan types are write-only). `kind` always first; body is `item`/`inner`/`fields`+`additional`/nothing. camelCase, owned ultimately by Kind's `PlanSerializer`. |
| **Merge** | `existing`, `incoming` | `(true, merged)` or `(false, null)` | `Any` is identity; `None` conflicts with everything; nullable is transparent; arrays/objects recurse. Object merge **unions fields** (a per-field conflict is a conflict); the result is `OpenObject` **only** when *both* inputs allow additional fields **and** the union is empty — otherwise it is a closed `ObjectOf(union)`, so `closed{a} + open{}` merges to the **closed** `{a}`. Conflict is a real value (`false`), never an exception. |
| **Accept** | `expected`, `actual` | bool | `Any` accepts/accepted-by anything; `None` accepts nothing; nullable transparent; arrays/objects recurse. For objects: an expected **open** object with no declared fields accepts any object; otherwise every expected declared field must be present-and-acceptable in `actual` — **except** a missing field is accepted when `actual` is open (`AllowsAdditionalFields`). So `CanAccept(closed{a}, open{})` = **true**, while `CanAccept(closed{a}, closed{b})` = **false**. |
| **Runtime apply** | `unknown` value + `Shape` | coerced `unknown` | Total, never throws on type mismatch — returns the original (`applyShape`) or `Err` (`convertByShape`). Missing input coerces to the shape's zero (`""`/`0`/`false`/`NaN`/`[]`/`null`). |
| **Runtime egress** | runtime value + declared `RuntimeShape` | wire value | `formatForWire` runs **exactly once** per value on the gather path (shape-once). Unshaped (`none`) → passthrough. |

**Null is unrepresentable by construction, not by exception.** The whole point of
`None` is that there is never a null `Shape` to defend against — `FromClrType`
total + `FromValue(null) → None` + factories that take a `Shape` (never null) +
the `None` sentinel close the hole. The two `ArgumentException`s in `ArrayOf`/
`Nullable` guard a *developer authoring mistake* (composing an array of `None`),
which is the legitimate authoring boundary, not normal-execution null defense.

### Coverage gate

Every Shape variant in P-SHAPE (`string · number · boolean · date ·
nullable<scalar> · array<item> · object{fields} · raw · any · none`) is covered by
at least one A/C fixture; every algebra branch (`==`/`None`/`Any`/`nullable`/`array`/
`object`/`conflict`) by a D fixture; every `applyShape` switch arm by an E fixture.
A new variant is not done until it appears in the TS `Shape` union, the C# factory,
an A or C fixture, and an E `applyShape` arm — the four places §3's "null
unrepresentable" + Kind's exhaustiveness contract require.
