FusionCarousel Raw EJ2 core Probe

Raw ej.navigations.Carousel probe for the Guided Care-Plan Review journey: three care-plan section slides (Medications, Therapy Goals, Discharge Steps), manual navigation only (autoplay and play-button off). Medications (index 0) is the locked sign-off gate: any move that would land back on it (nextIndex === 0) is cancelled via args.cancel = true. Drives only the onboarded runtime surface (selectedIndex read, next()/prev(), slideChanging/slideChanged payloads, payload cancel write). Empirical note proven by this probe: a prev() from index 0 does NOT raise slideChanging at all (EJ2 short-circuits it), so the cancel guard must key on nextIndex === 0 (a Previous from index 1), the move EJ2 actually raises. Execute through run-fusion-probe-trace.mjs --component carousel --api-set core; the trace is saved as traces/raw-ej2-core.trace.json.
